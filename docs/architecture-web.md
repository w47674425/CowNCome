# 赵云与阿斗 · Web 版架构设计

> 技术路线变更说明：原 `docs/architecture.md` 为 Cocos Creator 方案，已弃用（代码归档至 `archive/cocos-scripts/`）。
> 本方案为 **Vite + TypeScript + Canvas 2D 纯 Web 实现**，零引擎依赖，浏览器直接可玩，后续可无缝迁往微信小游戏。

## 1. 技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| 构建 | Vite 5 + TypeScript 5 | 秒级热更新，零配置，快速上线 |
| 渲染 | Canvas 2D（自研 Renderer） | 文字即视觉（汉字字牌），2D 足够，无引擎学习成本 |
| UI | DOM overlay | 菜单/HUD 用 DOM 开发效率最高，游戏画面用 Canvas |
| 状态 | 自研 BattleEngine（纯 TS 模拟器） | 零依赖可单测，未来可直接搬进服务端做权威校验 |
| 存储 | localStorage（StorageManager） | Phase1 本地存档 |
| 网络 | NetworkManager 适配器（本地 Mock） | 接口已对齐云函数方案，Phase2 换 HTTP 实现 |
| 广告 | AdManager（模拟实现） | 打通流程，上线前替换真实 SDK |

## 3. 核心系统设计

### 3.1 战斗模型（Random Dice 式对称竞速）

双方各自防守自己的棋盘，敌兵沿 4 条列道从顶部生成、向下逼近阿斗，**谁先漏死谁输**——"不需要完美防守，只需要比对手多撑一秒"。

```
玩家视角（1280x720 逻辑分辨率）:
┌────────────────────────────────────────────┐
│ 敌方阿斗血条 ─── 波次信息 ─── 对手动向        │
│  列道1  列道2  列道3  列道4   ← 敌兵出生      │
│ ┌──┐ ┌──┐ ┌──┐ ┌──┐                        │
│ │刀│ │弓│ │  │ │  │   棋盘 4x3              │
│ └──┘ └──┘ └──┘ └──┘   (初始解锁 6 格)       │
│              …                              │
│ 我方阿斗血条 ────── 操作栏(征兵/退兵/广告)    │
└────────────────────────────────────────────┘
```

### 3.2 核心循环（与 overview.md 三层循环一致）

- **即时层**：击杀敌兵 → 掉馒头 → 征兵（成本递增 10→270）→ 放置/合成 → 更强火力 → 循环
- **单局层**：6 格空间分配 + 1 次退兵救命 + 广告救阿斗 → "比对手多撑一秒"
- **长线层**：胜场/金币/图鉴字牌收集（Phase1 本地，Phase2 云端+段位+装备）

### 3.3 数值表

| 兵种 | 攻击 | 攻速(s) | 射程 | 成长系数 | 定位 |
|------|------|---------|------|---------|------|
| 刀 | 10 | 1.2 | 近战(0) | 1.35 | 前排拦截 |
| 枪 | 14 | 1.5 | 1 | 1.40 | 穿透，对后排+50% |
| 弓 | 18 | 2.0 | 6(全屏) | 1.45 | 远程炮台 |
| 骑 | 12 | 0.9 | 近战(0) | 1.30 | 高频输出 |

- 合成规则：同类同级合 → 等级+1（最高 5 级），攻击 × 成长系数
- 征兵：成本 `[10,15,22,32,46,66,94,134,190,270]`；掉落权重 兵76/字牌20/铲子4；字牌保底连续 12 抽必出
- 敌兵：HP `20 + 波次×8`，速度 `0.35 + 波次×0.02`（上限 0.6），漏怪扣阿斗 8 血
- 波次：每 7s 一波，数量 `2 + 波次×0.8`（上限 10），共 25 波
- 击杀掉落：`5 + 击杀者兵等级×2` 馒头（激励合成升级）

## 4. 数据流

```
输入(点击/按钮) → BattleScreen → BattleEngine(权威状态)
                                    ├→ EventBus(事件) → Renderer(Canvas)
                                    ├→ AIPlayer(对手决策)
                                    └→ 结算 → StorageManager(存档)
```

**原则**：BattleEngine 是唯一权威状态源；渲染层只读引擎状态 + 监听事件做特效；UI 只调引擎方法。引擎零 DOM/Canvas 依赖，可单测、可移植。

## 5. 运行与构建

```bash
npm install        # 安装依赖
npm run dev        # 开发（http://localhost:5173，自动开浏览器）
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```
